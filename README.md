# Product List with Cart

A responsive e-commerce product page built with React. Users can browse products, manage a shopping cart, and confirm an order through a modal interface.

> This project is based on a Frontend Mentor challenge and was developed to practice React fundamentals and modern frontend development.

## ✨ Features

- Responsive layout (Mobile First)
- Product list
- Add products to cart
- Increase and decrease product quantity
- Remove products from cart
- Dynamic cart total
- Order confirmation modal
- Order summary
- Reset cart after confirming an order

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/perfi-dev/product-list-with-cart.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
